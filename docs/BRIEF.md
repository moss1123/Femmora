## 1. The brand (from Group 1, MKTG 201, Deliverables 1 & 2)
- **Femmora** — a premium formal *workwear* house for Pakistan's women leaders. Tagline: **"For women who lead."** Motto: *"Power in every detail."* Promise: *"Dress the woman you are becoming."*
- **Gap it fills:** Pakistani brands sell either embellished *occasion wear* (Sapphire, Khaadi) or Western corporate wear (Generation, high street) that doesn't suit the local corporate climate. Working women are left with boxy cuts, inconsistent sizing, no formal Eastern option, fabrics that fail in the heat, no pockets, and the daily "what do I wear" decision.
- **Four differentiators:** (I) Made-to-measure (fixes boxy cuts & sizing), (II) Structured fusion cuts — power kurtas, tailored long vests: modest *and* authoritative, (III) Breathable, anti-crease fabrics with real deep pockets & non-sheer plackets, (IV) Wardrobe consultation — fixed, interchangeable capsule outfits that remove the morning decision.
- **Three tiers:** Core Ready-to-Wear (entry, instalments) · Made-to-Measure (own measurements, colour) · Premium Wardrobe Consultation (palette, silhouette, multi-piece capsule — a service, not just a product). See `TIERS` in `src/data/site.ts`.
- **Primary target — "Rising Leaders":** founders, managers, senior professionals, 27–40, Karachi first then Lahore & Islamabad. Persona *Sana, 32*: "My clothes should say I'm competent, and still say I'm me." Values competence, authenticity, time. Buys 2–4×/yr before pitches/board meetings. Reads reviews (new brand → social proof matters). Secondary: Career Starters 22–27 via Core RTW.
- **Research hooks you can use in copy:** social identity (75.1%) and professional status (65.0%) motivate working women; women hold only 3.3% of full-time corporate jobs in Pakistan → often the only woman at the table; heavy threadwork/glitter looks out of place in boardrooms — status is signalled through clean seams, sharp collars, structured silhouettes, fabric weight; the "double bind": too Western reads too bold/immodest, too traditional reads non-corporate; heavy Western blazers are unwearable 8 months a year; adaptive fits (flat-front trousers with concealed elastic backs, adjustable wrap silhouettes) for working mothers & postpartum bodies; packaging = rigid box + printed insert on re-wearing one piece three ways; channels = website, Instagram & WhatsApp booking, by-appointment studio; B2B leadership-presence programmes for banks, telcos, tech.
- **Moodboard:** The Modern Founder (visionary, unapologetic), The Executive (polished, timeless), The Equestrian (grace, heritage, discipline). Fabrics: velvet, silk, linen, cotton, wool, leather, satin, jacquard, embossed. Palette: burgundy, emerald, navy, ivory, camel, charcoal, black, gold. Taglines on the board: "More than clothing — a personality in progress", "Textures that speak", "Power in every detail", "Intentional colour", "Tailoring that empowers", "A wardrobe for every chapter".
- **Voice:** quietly confident, editorial, concise, British spelling (colour, personalise, programme). Never cutesy. Prices in PKR (e.g. `PKR 24,500`).

## 2. The site
Vite + React 19 + TypeScript. Routes: `/` (home: 3D clothing rack hero + scroll story), `/styling`, `/collection`, `/custom`.
On the home rack each garment = a page. Clicking one lifts it off the rail, flies it to the camera, zooms into the fabric, and floods the screen with the page's **flood colour**, which must equal that page's hero background so the hand-off is seamless:

| page | theme (`data-theme`) | flood / hero bg |
|---|---|---|
| `/styling` | `ivory` | `#f3ede2` (= `var(--ivory-200)`) |
| `/collection` | `wine` | `#2a0a12` (= `var(--wine-900)`) |
| `/custom` | `parchment` | `#e8dcc2` (= `var(--parchment)`) |

## 3. Design system — USE IT, don't reinvent it
- **Aesthetic:** luxury maison, Apple-grade smoothness. Navy, off-white/ivory, gold. Italic display type everywhere it matters. Generous negative space, hairline gold rules, editorial asymmetry, large italic numerals (I, II, III), small tracked uppercase labels. No rounded "SaaS" cards, no drop-shadowy UI kits, no emojis, no purple, no gradients other than the gold foil.
- **Tokens & classes:** `src/styles/global.css`. Colours `--wine-*`, `--ivory-*`, `--gold-*`, `--parchment`, `--champagne`; semantic `--bg --bg-elev --fg --fg-muted --fg-faint --line --line-soft --accent --accent-strong` (switch automatically with `data-theme="wine|noir|ivory|parchment"` on any wrapper). Type classes: `.display .h-hero .h1 .h2 .h3` (Bodoni Moda italic), `.lead .body .serif-italic` (Cormorant Garamond), `.label .label-sm` (Jost tracked caps), `.numeral`, `.gold`, `.gold-text` (foil), `.muted`. Layout: `.container`, `.section` (vertical rhythm + themed bg), `.rule`, `.rule-gold`, `.frame` (image box), `.page` (page root), `.sr-only`. Eases: `var(--ease-lux)`, `var(--ease-silk)`; GSAP custom eases `'lux'`, `'silk'`, `'drape'`.
- **Fonts** are already loaded: `var(--font-display)` Bodoni Moda (use italic), `var(--font-serif)` Cormorant Garamond, `var(--font-sans)` Jost.
- **Components (import, don't copy):**
  - `components/TLink` — `<TLink to="/custom#book" cursor="Book">` for ALL internal links (runs the transition system). Hook `useGo()` from `hooks/useGo` for programmatic navigation. Never use react-router `<Link>`/`navigate` directly.
  - `components/Button` — `<Button variant="gold|outline|ghost|solid" to="/x">Label</Button>` or as a `<button>` (onClick, type, disabled).
  - `components/Reveal` — `<Reveal delay>` fade-rise on view; `<SplitReveal as="h2" className="h2" trigger="scroll|load" by="lines|words|chars">` masked line reveal (GSAP SplitText); `<ImageReveal src alt parallax from>` clip-wipe + parallax image; `<Eyebrow numeral="II">Label</Eyebrow>`.
  - `components/Marquee` — italic infinite marquee reacting to scroll velocity.
  - `hooks/useGo` → `usePageReady()` — true once the transition cover has lifted. Gate hero intro animations on it.
  - `lib/motion` — import `{ gsap, ScrollTrigger, SplitText, Flip, useGSAP, scrollToTarget, prefersReducedMotion }` from here (plugins registered, Lenis smooth-scroll synced). `motion/react` (Framer Motion v12 API: `motion`, `AnimatePresence`, `useScroll`, `useTransform`, `useInView`, `LayoutGroup`, `layoutId`) for component-state/UI animation.
  - `store/cart` — `useCart` (`items, open, add, remove, setQty, clear, setOpen`), helpers `cartCount, cartTotal, formatPKR`.
  - `data/site` — `BRAND, PAGES, DIFFERENTIATORS, TIERS, TESTIMONIALS, IMAGES`.
- **Custom cursor:** any element with `data-cursor="Label"` shows that label in the gold cursor ring (`data-cursor=""` grows without a label). Links/buttons grow automatically.
- **Nav** is fixed (height `var(--nav-h)`), auto-inverts based on the `data-theme` of whatever is under it — so EVERY section must sit inside an element with a `data-theme`. Leave `calc(var(--nav-h) + …)` top padding in heroes.
- **Global Footer** is rendered by App after every page — do not add your own footer.

## 5. Engineering rules
- TypeScript strict; `noUnusedLocals`. Function components + hooks. One CSS file per page/section, co-located, with a **unique class prefix** for your area (`hs-` home story, `sty-` styling, `col-` collection, `cus-` custom). No Tailwind, no CSS modules, no inline `<style>` blocks for large CSS.
- Page root: `<div className="page" data-theme="…">`. Hero background must equal the flood colour. Content must be responsive down to 375 px wide with no horizontal scroll (`overflow-x: clip` where needed).
- GSAP inside `useGSAP(() => {...}, { scope, dependencies })` so it auto-reverts; ScrollTrigger pins must use `pinSpacing` sensibly and work with Lenis (it's already synced; don't create another smooth scroller). Avoid pinning on screens < 768 px wide if it hurts UX — use `gsap.matchMedia()`.
- Animate only `transform`, `opacity`, `clip-path`, `filter`. Respect `prefersReducedMotion()`.
- Accessibility: semantic landmarks/headings (one `h1` per page), `alt` on images, labelled form fields, visible focus, buttons are `<button>`, keyboard-operable tabs/accordions/modals (Escape closes, focus returns), `aria-*` where appropriate. Modals/drawers that scroll need `data-lenis-prevent`.
- No network calls; forms are demo-only (validate, then show an elegant confirmation).
- **Ownership:** only create/edit files inside your assigned area (listed in your task). Do NOT edit shared files (`App.tsx`, `main.tsx`, `styles/global.css`, `components/*` except where your task explicitly grants one, `data/site.ts`, `store/*`, `lib/*`, `hooks/*`, `three/*`). If you need something shared, build it inside your area.
- **Verify:** run `npx tsc -p tsconfig.app.json --noEmit` from the project root and fix every error in YOUR files (ignore errors in files you don't own — others are working in parallel). Do not run the dev server, `vite build`, or browser tools.
